# 项目架构图

这是 Mermaid 流程图，用于描述当前项目架构。实线表示已实现流程；虚线表示未来接入关系。标注“待实现”的模块目前不参与编译。

使用支持 Mermaid 的 Markdown 编辑器（例如 Typora）打开本文件即可查看图形；VS Code 需要启用支持 Mermaid 的 Markdown 预览扩展。普通文本编辑器只能看到图的源码。

路由算法集中在 `routing.py`，图中各算法步骤不是独立的框架模块。

```mermaid
flowchart TB
    IN["输入线路<br/>QuantumCircuit / OpenQASM 2"]
    ENTRY["端到端入口：compile_processor<br/>pipeline.py"]

    subgraph LOGIC["逻辑编译层 · 已实现"]
        FRONT["静态前端与魔法态转换<br/>magic_states.py<br/>T / CCZ → 选定分支的 Clifford trace"]
        PRE["预处理：preprocess.py<br/>CX 展开；构建完整 G1 与 CZ 投影 G2"]
        OPT["Rotation 优化<br/>Trivial / Greedy / SAT / Window SAT"]
        DAG["完整逻辑 IR：CompiledCircuit<br/>NetworkX DAG + CompiledNode<br/>插入 rot；S → folding → icz → S → unfolding"]
        FRONT --> PRE --> OPT --> DAG
    end

    IN --> ENTRY --> FRONT
    OIF["已有策略接口：optimizer(prepared)<br/>返回 rotation 插入位置"] --> OPT

    subgraph SPACE["空间编译层 · 已实现"]
        HW["ProcessorConfig → Processor<br/>hardware.py<br/>zone / site / patch / patch pair 几何"]
        subgraph ROUTING["routing.py · 函数式实现"]
            BS["build_cz_blocks + initial_mapping<br/>CZ/icz block 序列 BS；初始 Mapping"]
            LOOP["route_and_schedule 调度主循环<br/>普通指令优先 → deformation → CZ/icz"]
            GROUP["partition_block<br/>贪心着色；逻辑比特冲突与 pair 容量"]
            PLACE["assign_positions<br/>PowerMove 位置分配<br/>返回二维最近空闲 data patch"]
            AOD["plan_aod_stages<br/>移动依赖、环缓冲、非交叉分组<br/>依赖约束下的 stage 排序"]
            BS --> LOOP
            LOOP --> GROUP --> PLACE --> AOD
            AOD -->|"更新位置，记录移动及门操作"| LOOP
        end
        SIR["空间调度 IR：RoutingSchedule<br/>Mapping + BS + InstructionBlock 序列<br/>Move / 最终位置 / cost"]
        CHECK["validate_schedule<br/>重放检查：依赖、优先级、资源、移动、最终状态"]
        LOOP -->|"全部指令完成"| SIR --> CHECK
        HW --> BS
        HW --> PLACE
        HW --> AOD
        HW --> CHECK
    end

    DAG -->|"已有跨层接口：完整 DAG 与节点元数据"| BS
    MIF["已有接口：mapping=None<br/>可传入初始 Mapping"] --> BS
    CIF["已有接口：cost_fn(stages)<br/>默认 len；当前仅计算代价<br/>不自动改变规划算法"] --> SIR

    subgraph OUT["输出与查看 · 已实现"]
        JSON["save_compilation / load_compilation<br/>带版本的 JSON；加载后重新校验"]
        LV["visualize.py<br/>逻辑线路图"]
        HV["hardware_visualize.py<br/>初始位置、逐 AOD stage、最终位置"]
    end
    CHECK --> JSON
    DAG --> LV
    CHECK --> HV
    HW --> HV

    subgraph FUTURE["未来下层编译 · 待实现"]
        LOWER["待实现：码块内部 lowering<br/>rot / folding / unfolding 原子移动<br/>icz 的物理操作数与内部 CZ 展开"]
        SECOND["待实现：空间约束与二次调度<br/>多个码块 deformation 的并行优化"]
        SE["待实现：Syndrome Extraction<br/>辅助码块动态搬运"]
        DYNAMIC["待实现：完整资源态运行流程<br/>魔法态工厂、制备、真实测量反馈与动态分支"]
        TIME["待实现：耗时模型与时间轴优化<br/>物理操作时间与硬件执行序列"]
        LOWER --> SECOND --> TIME
        SE --> TIME
        DYNAMIC --> TIME
    end

    DAG -.->|"预留数据边界：kind / qubits / source_node / reset_epochs"| LOWER
    SIR -.->|"预留接入点：deformation IB 与位置状态"| LOWER
    HW -.->|"已有 site_position / patch_sites 等几何接口"| LOWER
    SIR -.->|"已有固定 ancilla Mapping；动态流程未实现"| SE
    FRONT -.->|"当前只支持静态 trace"| DYNAMIC
    CIF -.->|"未来扩展目标；耗时模型尚未实现"| TIME

    classDef future fill:#fff3df,stroke:#bd791d,stroke-dasharray:5 4,color:#49310e;
    class LOWER,SECOND,SE,DYNAMIC,TIME future;
```

内部移动和二次调度目前仅保留 DAG、deformation IB、位置与几何数据的接入边界，没有已实现的插件接口或空接口类。
